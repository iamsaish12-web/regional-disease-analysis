
# Regional and Disease-Specific Outbreak Analysis

## Project Overview
This project uses Python to analyse regional and disease-specific outbreak data. It explores disease distribution, geographical patterns and changes in reported cases over time.

## Objectives
- Analyse disease cases across different states and districts.
- Identify diseases with the highest reported cases.
- Study year-wise and month-wise disease trends.
- Identify districts with the highest reported cases.
- Perform statistical analysis using non-parametric tests.
- Visualise outbreak patterns using graphs and heatmaps.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

## Visualisations
1. Top 10 diseases by reported cases.
2. Year-wise disease trend.
3. Top 10 districts by reported cases.
4. Month-wise reported cases.
5. District-wise monthly heatmap.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Place `Final_data.csv` in the project directory.
4. Open the notebook using Jupyter Notebook or Google Colab.
5. Run all cells.

## Project Files
- `Copy_of_Regional_Disease_Analysis_with_4_Graphs.ipynb` – Main analysis notebook.
- `Final_data.csv` – Dataset (if redistribution is permitted).
